#  Online Quiz Application  

A lightweight, interactive **Quiz Web App** built with **HTML, CSS, and JavaScript**.  
It allows students and educators to practice MCQs with timers, instant feedback, and scoring.  
Users can also **create their own quiz** with custom questions.  

---

##  Features  
-  Multiple-choice questions  
-  Per-question timer  
-  Instant scoring & feedback  
-  Correct & wrong answers highlighted  
-  Restart & review answers after quiz  
-  **Create Your Own Quiz** mode (add custom questions, options, and answers)
